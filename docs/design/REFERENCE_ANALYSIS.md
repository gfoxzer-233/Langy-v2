# Langy Reference Analysis

Scope: public product pages, store screenshots, and published help/review pages only. The goal is to adapt common language-learning UX patterns without copying protected mascots, layouts, artwork, sounds, text, or brand systems.

| App | Screen / area | Useful pattern | Why users understand it | Adapt for Langy | Do not copy | Langy decision |
| --- | --- | --- | --- | --- | --- | --- |
| Duolingo ([site](https://www.duolingo.com/), [home path article](https://blog.duolingo.com/new-duolingo-home-screen-design/), [Google Play](https://play.google.com/store/apps/details?id=com.duolingo)) | Home, path, lesson feedback | One obvious next step, large tap targets, completed/current/locked progression, instant feedback | The user always knows what to do next and sees progress after each answer | Keep one primary lesson CTA on Home and clear current/next unit state | Owl, exact path visuals, copy, sounds, green brand palette | Home centers mascot, active lesson, course progress, and one round Talk entry |
| Babbel ([site](https://www.babbel.com/), [Google Play](https://play.google.com/store/apps/details?id=com.babbel.mobile.android.en)) | Structured lessons, review, paywall | Calm adult visual hierarchy, real-life dialogue framing, readable lesson cards | Paid learners expect clarity and structure, not only game mechanics | Use quieter premium cards, mature typography, practical lesson goals | Babbel colors, exact lesson copy, checkout copy | Langy uses warm premium surfaces with structured lesson metadata |
| Busuu ([site](https://www.busuu.com/), [App Store](https://apps.apple.com/app/busuu-language-learning/id379968583)) | CEFR, course map, progress | Level-based course structure and visible study progress | CEFR gives learners confidence that the course has a destination | Show level progress and current unit from active curriculum | Busuu badge style, screenshots, exact level presentation | Course card shows current locked course and progress without Home course switching |
| Memrise ([site](https://www.memrise.com/), [TechRadar overview](https://www.techradar.com/reviews/memrise)) | Native phrases, conversations | Short phrase practice connected to conversation mode | Learners see vocabulary as usable speech, not isolated lists | Connect lesson vocabulary to Omar Talk scenarios | Memrise videos, characters, copy, icon style | Summary can suggest speaking, but Home Talk remains a single round entry |
| Speak ([site](https://usespeak.com/), [App Store](https://apps.apple.com/us/app/speak-language-learning/id1286609883), [Google Play](https://play.google.com/store/apps/details?id=com.selabs.speak)) | Voice-first Talk | Large round microphone, clear voice states, scenario choices | Speaking state is obvious: idle, listening, processing, retry | Make Omar Talk a dedicated full-screen voice flow with a circular mic | Speak UI composition, branding, scripts | Home opens a Talk modal; Talk route hides bottom nav and uses a round mic |
| ELSA Speak ([site](https://elsaspeak.com/), [pronunciation FAQ](https://support.elsaspeak.com/hc/en-us/articles/360047006231-How-does-ELSA-score-my-pronunciation)) | Pronunciation feedback | Feedback split into understandable skill dimensions | Learners can act on pronunciation feedback instead of seeing only a score | Keep explicit fallback and honest unavailable states for speech/AI | ELSA scoring UI, exact terminology, waveform visuals | Speaking widgets never block lesson completion; Talk has text fallback |
| Drops ([site](https://languagedrops.com/), [TechRadar overview](https://www.techradar.com/reviews/drops)) | Visual vocabulary tasks | Short playful interactions, big choices, quick reward rhythm | Low-friction tasks reduce fatigue on mobile | Use larger choice cards and short exercise rhythm | Drops illustration style, exact mechanics, palette | Exercise widgets share clearer card/buttons while keeping Langy content |
| LingQ ([site](https://www.lingq.com/)) | Reading/listening library | Learners can move from lesson to authentic input | Intermediate learners expect more than drills | Future: add reading/listening tracks after lesson engine is stable | LingQ reader UI, library data, copy | Not implemented in this visual pass |

Core constraints preserved:

- Course language is selected before payment and locked after entitlement.
- Home does not include a course switcher.
- Settings remain for interface language, not purchased course switching.
- Talk is removed from bottom navigation and opens from the single round Home button.
- Langy keeps its own mascot, palette, illustration direction, microcopy, and lesson methodology.
