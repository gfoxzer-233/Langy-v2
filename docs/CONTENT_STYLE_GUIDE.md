# Content Style Guide

Дата: 2026-07-13

## Урок

Каждый урок должен отвечать на вопрос: что пользователь сможет сделать после урока.

Хорошо:

- `Поздороваться, назвать имя и спросить имя собеседника.`
- `Заказать напиток в кафе простыми фразами.`
- `Объяснить причину проблемы с помощью because / so.`

Плохо:

- `Изучить Unit 2`
- `Пройти Present Simple`
- `Улучшить английский`

## Упражнения

Каждое упражнение должно быть связано с:

- `lessonObjective`
- `skillId`
- `cefr`
- `difficulty`
- `expectedAnswer`
- `acceptedAnswers`
- `explanation`
- `mistakeCategory`
- `reviewStrategy`

## Distractors

Нельзя использовать варианты, которые очевидно не относятся к навыку.

Плохо:

- `I am happy` варианты: `am`, `banana`, `airport`

Хорошо:

- `I ___ happy` варианты: `am`, `is`, `are`

## Feedback

Feedback после ошибки:

1. Коротко назвать правильный ответ.
2. Назвать тип ошибки.
3. Дать один пример.
4. Поставить навык в review queue.

Не нужно давать длинную лекцию внутри одного виджета.

## Speaking

Speaking не должен быть наказанием после урока. Это вторичная добровольная практика:

- free talk;
- lesson topic;
- recent mistakes;
- 3-5 min scenario;
- resume unfinished session.
